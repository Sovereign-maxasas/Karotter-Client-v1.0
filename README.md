# Karotter-Client-v1.0
Karotterをキーボードで快適に操作するためのTampermonkeyスクリプトです。

投稿操作やページ移動をショートカットキーで簡単に行えます。

## ✨ 特徴

- キーボードだけでKarotterを操作
- 投稿ごとの操作に対応
- TL更新を高速化
- シンプルなショートカット表示付き

## ⌨️ ショートカット

| Key | Action |
| 1 | ホーム |
| 2 | 検索 |
| 3 | 通知 |
| 4 | メッセージ |
| 5 | ブックマーク |
| 6 | コミュニティ |
| 7 | プロフィール |
| D | TL更新 |
| E | いいね |
| R | リカロート |
| W | 引用RK |
| S | リプライ |
| N | カロート |

## 📦 インストール

### 1. Tampermonkeyをインストール

Tampermonkeyをブラウザに追加してください。

### 2. スクリプトをインストール

以下のファイルを開いてインストールしてください。

`Karotter-Keyboard-Plus.user.js`

## ⚠️ 注意
- Karotterの仕様変更により動作しなくなる場合があります。
- Tampermonkeyが必要です。
- PCブラウザ向けです。
- ショートカット一覧にwindowsの絵文字を利用しているため、mac環境ではうまく表示されない可能性があります。ご了承ください。
